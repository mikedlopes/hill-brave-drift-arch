## P0 — first print without getting lost

Ship these before P1.

- [x] **Print-this card** on the download strip: 0.20 mm · 3 walls · 20% infill · no supports · tray floor-down · lid lip-down · unzip = two STLs
- [x] **Recommended lock**: Snap + Standard + Thick HDMI + Keyring on. Visible “recommended” when those are set. **Reset to recommended** when they drift.
- [x] **Human labels**
  - Closure: No screws / M2.5 screws
  - Fit: Snug · Standard · Loose (Standard = use this)
  - HDMI: Thick plug / Slim plug — “if you don’t know, Thick”
  - Keyring: On / Off (On is the current model)
- [x] **Looks disclosure**: Lattice + step size folded. Default closed. First control is no longer a Voronoi slider.
- [x] **Honesty as three lines**, not one orange dump
  - Nobody has printed this cut
  - GPIO is a cover, no HATs
  - CSI is a ribbon window, not a camera
